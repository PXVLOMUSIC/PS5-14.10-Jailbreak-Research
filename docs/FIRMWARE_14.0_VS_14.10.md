## Source-level differences

Sony's WebKit_1400 source drop is labeled "For PlayStation®5 system software version 14.00 -" (i.e., 14.00 and above, including 14.10). This means **the same source tree covers both 14.0 and 14.10**. No separate source drop exists for 14.10.

### Changes.txt analysis

The `WebKit-1400-changes.txt` lists Sony's modifications. Only 4 commits are dated 2026:
- BMP RLE24 decoder (Aug 29)
- 44-file crash-fix bundle (Aug 24)
- PlayStationWebView.cpp (Jul 1)
- YarrPattern.cpp (Apr 27)

None of these touch `html/canvas/` or the scrolling-thread timer. Both CVE-2026-43720 (Canvas UAF) and the RunLoop::Timer UAF (BZ 315533) are structurally live in both 14.0 and 14.10.

## Conclusion

**At the source level, 14.0 and 14.10 are the same.** The WebKit_1400 source drop covers both. The differences are at the **binary/runtime level** (offsets, allocator behavior, syscall stubs), which require device measurement.

If you have a 14.0 console, running the probes in `probes/` will determine whether 14.0 behaves identically to 14.10 or has differences.
